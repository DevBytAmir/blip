## [1.0.0] - 2026-09-26

### Added

- Type any word and see it turned into Morse code live, with the literal dot/dash sequence shown as a caption
- Nine geometric layouts for the pattern: grid rows, concentric circles, radial spokes, single spiral, honeycomb capsules, barcode bars, wave line, orbiting ellipses, pixel matrix
- Style presets (Bold & Blocky, Delicate & Thin, Retro Terminal, Playful) plus manual stroke width, spacing, rotation, and frame shape controls, with sliders that gray out when a control doesn't apply to the current geometry
- Seven color themes with solid and gradient fills, plus fully custom solid/gradient colors for the background and mark independently
- Square, circle, and rounded-square frame options
- Randomize button with one-step undo
- Export to PNG (with preset or custom resolution) or SVG
- Shareable links that encode the full design in the URL, and a local "Stash" to save designs in the browser
- Light and dark theme, following your system preference by default
- Geometry options gray out (without disabling) when the current word would look cramped in that layout
